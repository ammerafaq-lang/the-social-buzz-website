# The Social Buzz Website

Production website for The Social Buzz, a Dubai-based creative marketing agency.

## Stack
Static HTML, CSS and JavaScript. No build step required.

## Features
- Responsive premium dark/light visual system
- Work filters and project overlays
- Service and industry positioning
- Client workflow previews for calendar, brief and project flow
- Founder-led creative direction section
- Netlify project enquiry form with honeypot spam protection
- SEO metadata, Open Graph, JSON-LD, sitemap and robots.txt
- Privacy, success and 404 pages

## Local preview
Open `index.html` directly or serve the folder with a static server.
